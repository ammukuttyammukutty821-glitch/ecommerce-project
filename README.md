# ShopSmart - MERN E-Commerce Application

ShopSmart is a full-stack e-commerce application built using the MERN stack.

## Technologies Used

### Frontend
- React.js
- React Router
- Axios
- Redux Toolkit
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs

## Features

- User Registration and Login
- JWT Authentication
- Product Listing
- Product Search
- Product Filter
- Product Sort
- Product Details
- Shopping Cart
- Order Management
- User Profile
- AI Product Recommendations
- Contact Form
- Responsive UI

## Project Structure

- `E-commerce backend` - Backend API
- `ecommerce-frontend` - React Frontend

## How to Run

### Backend

```bash
cd "E-commerce backend"
npm install
npm start
